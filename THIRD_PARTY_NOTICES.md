# Third-party notices

Registry's `FacetedFilter.svelte`, `FilterChip.svelte`, and `BulkActionsBar.svelte` adapt interaction and composition patterns from [SV Table](https://github.com/SikandarJODD/sv-table). Meadow replaces its shadcn popovers, commands, styles, and client-side filtering with native popovers, existing Meadow primitives, and server queries. No shadcn configuration or token system is installed. The shadcn-svelte table sources were consulted as reference; their license is retained below too.
