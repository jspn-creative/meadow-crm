## Implementation choices

- Propose the vocabulary entry before adding it: **Flag**, Field belonging to Client — a shared review marker with an optional note, independent of tags, Consent, archive state, and historical Imported data hints. The developer supplied the name and requested this behavior. Edit `src/lib/glossary/vocabulary.ts`, then run `vp run vocabulary`; do not edit generated tables.
- One flag per client: `flagged` is non-null boolean, default false; `flagNote` is non-null plain text, default empty. Trim and limit notes to 2,000 characters on server and client. Flagged-without-note is valid. Clearing a flag clears its current note, retaining the previous value in History; archive/restore preserves both. These are bounded implementation choices, not a multiple-flag or tag system.
- Use `integer("flagged", { mode: "boolean" }).notNull().default(false)` and `text("flag_note").notNull().default("")`, with no new table-level flag CHECKs. Validate booleans, trimmed note length, and the resolved flag/note pair at the server write boundary; the data migration must satisfy the same invariants. SQLite's boolean mapping alone is not a database constraint. Do not describe this trade-off as database-enforced validation.
- Use the existing client editor for add/edit/clear. Give flagged Registry rows an icon plus subtle accent-family emphasis, retaining distinct selected/focused states and sticky-cell tint. No new flag filter, sort column, bulk-flag UI, notifications, or general overlay framework is needed.
- Default sort is distinct from explicit name A–Z: missing/invalid `sort` means `default`; default SQL order is `flagged DESC, name COLLATE NOCASE ASC, id ASC` before LIMIT/OFFSET. Explicit sorts never promote flags. A bare `sortDir` does not select a method.
- Keep the refresh repair local to the Registry's confirmed queries. The current mutation refresh updates the requesting browser; it is not a cross-user subscription. Navigation/focus refresh and visible polling must actually be wired before claiming the Registry portion of REC-6. This does not complete whole-app polling, dashboard date rollover, or the unrelated reliability milestone.
